- [ ] Landing page and brand identity.

- [ ] Dashboard with real or clearly labelled demo metrics.
- [ ] Create, list, edit and delete events.
- [ ] Event details workspace.
- [ ] Task CRUD and completion.
- [ ] Budget and expense calculations.
- [ ] Guest list and RSVP status.
- [ ] AI planner integration OR clearly labelled sample-plan fallback.
- [ ] Loading, empty and error states.
- [ ] No dead buttons.
- [ ] Public GitHub repository.
- [ ] Repository under 10 MB.
- [ ] Walkthrough video under 4 minutes.

## Submission verification
- [ ] Repository visibility is Public.
- [ ] README includes setup and feature list.
- [ ] `.env` is not committed.
- [ ] `.env.example` contains names only, no secrets.
- [ ] `node_modules`, build output and caches are excluded.
- [ ] Fresh clone can install and run.
- [ ] Demo link opens and video is less than 4 minutes.
- [ ] Demo shows actual working flows, not only static screens.
