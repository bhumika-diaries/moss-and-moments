# Walkthrough Demo Script — under 4 minutes

Target duration: 3:30. Record the real application, not slides. Only demonstrate features that work.

| Time | Screen / action | Narration |
|---|---|---|
| 0:00–0:15 | Landing page | “This is Moss & Moments, a woodland-inspired AI event planning companion. It brings event details, tasks, guests and budgets into one workspace.” |
| 0:15–0:40 | Dashboard | “The dashboard gives organizers a quick view of their upcoming events, pending tasks and budget progress.” |
| 0:40–1:20 | Create an event | “I can create an event by entering its name, type, date, location, guest count and budget. The event is then available in my workspace.” |
| 1:20–2:05 | AI planner | “The planner uses event details to produce a starting plan with ideas, a checklist and a suggested budget. The user can review and adjust the suggestions.” |
| 2:05–2:35 | Tasks | “The checklist turns planning into manageable actions. Tasks can be added and marked complete.” |
| 2:35–3:05 | Budget | “Expenses are recorded by category, and the app calculates spending against the event budget.” |
| 3:05–3:25 | Guests | “The guest list tracks invitations and RSVP responses.” |
| 3:25–3:30 | Closing | “Moss & Moments — little details, beautifully planned moments.” |

## Recording checklist
- Close unrelated tabs and notifications.
- Use a clean browser window and readable zoom.
- Prepare one sample event and realistic sample data in advance.
- Do not show API keys, personal data or private dashboards.
- Keep the video under 4:00.
- Upload the video to an approved public/unlisted video host or submission platform and add the link to README.
- Test the video link in a private/incognito window.
