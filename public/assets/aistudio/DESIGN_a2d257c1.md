# Design System — Moss & Moments

## Brand
**Moss & Moments** — “Little details. Beautifully planned moments.”
Personality: warm, thoughtful, whimsical, organized, reassuring.

## Visual direction
Use the supplied Fig Ficus image as the primary aesthetic reference. Think illustrated woodland journal meets usable SaaS dashboard. Do not copy the image; use its mood, framing and hand-drawn character.

## Tokens
| Token | Hex | Usage |
|---|---|---|
| parchment | `#F4E8D9` | App background |
| cream | `#FFF8EF` | Cards and surfaces |
| wood | `#63463C` | Sidebar, headings, strong accents |
| cocoa | `#392D29` | Body text |
| sage | `#A6A98A` | Secondary surfaces |
| olive | `#777B59` | Primary actions / active states |
| mauve | `#B58D99` | Secondary accent |
| mushroom | `#D6BDA5` | Borders and dividers |

## Typography
- Display: Cormorant Garamond (serif).
- Body/UI: Nunito (sans-serif).
- Decorative handwritten accent: Caveat (use sparingly).
Use readable sizes and sufficient contrast.

## Components
- Buttons: rounded, solid olive or wood; clear hover/focus/disabled states.
- Cards: cream surface, subtle warm border, 12–18px radius.
- Inputs: cream/white surface, visible label, clear validation.
- Sidebar: wood-brown surface with cream text and clear active item.
- Status chips: muted, readable, consistent.
- Empty states: small woodland illustration + helpful next action.
- Dialogs: focused, keyboard accessible, close/cancel actions.

## Layout
- Desktop: fixed/collapsible left navigation, content area with max-width.
- Mobile: compact top bar and drawer/bottom navigation; no horizontal overflow.
- Use consistent spacing (4/8/12/16/24/32px).
- Avoid overdecorating data tables and forms.

## UX rules
Every visible button must work. Show loading, success, empty and error states. Keep forms short and explain required fields. Do not use decorative imagery that obscures information. Respect reduced-motion preferences.
