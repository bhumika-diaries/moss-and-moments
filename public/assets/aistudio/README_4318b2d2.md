# Moss & Moments 🌿
**Little details. Beautifully planned moments.**

A whimsical, GenAI-powered event planning companion for organizing celebrations, budgets, guests and tasks.

## MVP features
- Event creation and management
- AI-assisted event plan generation
- Task checklist
- Budget and expense tracking
- Guest list and RSVP management
- Woodland-inspired responsive UI

## Tech stack
React + Vite, CSS/Tailwind, Supabase (Auth/PostgreSQL/Storage), Gemini API through a secure server-side function.

## Run locally
1. Install Node.js (LTS).
2. Clone this repository.
3. Run `npm install`.
4. Copy `.env.example` to `.env` and fill in the required values.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal.

## Environment variables
See `.env.example`. Never commit `.env` or API secrets.
